# dsh-tavern-fate-dice（命运之骰工作台 2.0）

面向 DSH Tavern（插件 API v8+）的原创无感动态技能检定、叙事阻尼器双向联动与多轨随机事件工作台插件：

- **进驻「插件区」统一工作台**：通过 `tavernUi.registerPanel` 注册常驻侧栏面板（桌面端与手机竖屏单列自适应，自动适配明暗主题），无额外聊天输入框干扰——玩家只需在主输入框正常打字发送，后台自动判断是否需要掷骰、匹配角色技能并裁定难度。
- **叙事阻尼器单趟合并提问 × 双向联动**：
  - 未开启叙事阻尼器时，独立调用宿主 `decisionJudge`（内置 R18 三级语义分级脱敏与本地启发式兜底）；
  - 开启叙事阻尼器时，将检定附加题合并进阻尼器的**单趟决策请求**（零额外往返耗时），自动复用阻尼铺垫分与四维心理/信任状态修正检定 DC，并在真骰出点后通过 `applyDamperDiceShift` 反向同步阻尼器的推进档位与 MVU 变量结算配额（大成功破局解锁突破配额、失败收紧防倒挂涨好感，同时严守反越权/防吃书红线）。
- **角色技能检定体系（内置 12 套世界观样板）**：支持 `2d6`、`d10`、`d20`、`d100` 四种骰制与加值预算分配器（一键随机分配正负特长/恢复推荐值），内置 `5e 标准（18项）`、`日常`、`修仙`、`侦探`、`武侠`、`西幻冒险`、`末日生存`、`赛博科幻`、`都市异能`、`校园成长`、`宫廷权谋`、`诡秘惊悚` 12 套样板，并支持可选叠加角色卡 MVU 变量修正。
- **多轨随机事件池 & 剧情增强 3.2**：
  - 支持 `d1 常驻要求`、`d2~d20 等权骰`、`d100 范围区间表` 与相对权重池，内置一键载入「通用剧情样板」（常驻演绎肘击 + 进展波折 + 情绪氛围 + 叙事节奏）；
  - 支持「长期组 + 当前场景组」双轨叠加、每轮剧情推动/氛围描写独立上限、同主题 2 轮冷却、5 轮临时主题屏蔽、下一轮暂停随机推动、MVU/输入/剧情线 AND 条件过滤与场景切换自动停用；
  - 基于原生后台结算（`settlementSection` + `settlementTool` + `saveTurnData`）维护最多 3 条**持续剧情线**，回退与分叉自动按版本隔离，不污染角色卡 MVU Schema。
- **跨局共享组库 & 配置导入导出**：支持多组打包导出 JSON、本地预览安全导入（重名自动加序号），并原生兼容直接导入 `AutoRandomInput` v1/v2 JSON 配置文件。

## 安装

### 方式一：一键导入安装包（推荐）

在 GitHub 仓库下载源码包或 Release ZIP，并在 DSH Tavern 的「设置 → 酒馆插件 → 导入插件」中选择导入即可。

### 方式二：手动克隆到用户插件目录

```sh
git clone https://github.com/bigmalove/dsh-tavern-fate-dice.git <dataRoot>/plugins/dsh-tavern-fate-dice
```

刷新酒馆页面后，在右侧「插件」卡片区点击 **命运之骰** 即可打开工作台。

## 开发与测试

```sh
# 校验并生成浏览器端 client.js
node build.mjs
node build.mjs --check

# 运行全套单元测试与打包检查
npm test
```
